1. Abrir la rama `estudio/paridad-python-rust-20261119` de `MatiGaete2023/flow` o la carpeta local `flowrust/flow-flow-python`.
2. Leer [diseño](DISENO.md), [registro](REGISTRO_IMPLEMENTACION.md) y [plan](PLAN.md). La compilación se hace desde `app/Cargo.toml`.

4. Anotar pruebas y pendientes, comprobar que el ejecutable siga reproduciendo el diseño local y publicar en la misma rama.
