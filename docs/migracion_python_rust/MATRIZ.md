# Matriz de paridad funcional

Cada fila es una capacidad que se puede demostrar desde la GUI, la CLI o un archivo de entrada. **Presente** significa que se localizó la ruta de código. **Parcial** identifica una diferencia concreta. **Por demostrar** exige una prueba equivalente antes de decidir si hay que programar. **Ausente** se refiere a la superficie indicada, en las versiones fijadas. Los criterios de la última columna son pruebas futuras salvo las ejecuciones enumeradas en VERIFICACION.md.

Abreviaturas de rutas: **P** = `src/nurus/personal/`; **C** = `rust/crates/`. El prototipo se encuentra en `prototipos/flow-egui/src/`. Los nombres de archivo y las funciones permiten buscar en el inventario.
