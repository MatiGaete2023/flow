# Informes de agentes en paralelo

Un archivo por agente y fecha (`AGENTE_<letra>_<fecha>.md`) con lo hecho, las pruebas, los runs de CI y el texto propuesto para `ESTADO.md`, `PLAN.md` y el registro. Los escribe el agente en su rama; el coordinador los integra. Ver «Trabajo en paralelo» en `AGENTS.md`.
