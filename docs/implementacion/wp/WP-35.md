# WP-35 · Instaladores con dependencias fijadas

- **Asistente (`Instalar_CSMP.bat`):** busca Python 3.12 primero (launcher, rutas y comandos), detecta la versión del
  entorno, instala `requirements\windows-py3XX.lock` con `--require-hashes` y luego el paquete con
  `--no-deps --no-build-isolation .`; mantiene `--no-index --find-links paquetes` si existe la carpeta; error claro si
  falta el lock. Los extras Excel/Outlook (xlrd, pywin32) vienen en el lock.
- **Descargador:** `Iniciar.cmd` crea el entorno con `py -3.12` y cae a `py -3`/`python`; `preparar_entorno.py` usa el
  lock con hashes de la versión en uso y solo si la copia no lo trae cae a `requirements.txt` (con aviso).
- **Pruebas:** `tests/test_windows_installer_contract.py` (+2 pruebas y orden 3.12→3.14). La prueba con `cmd.exe` real
  sigue omitida en Linux; **pendiente CI Windows verde** (requiere PR).
- **Riesgo (N2):** si una oficina instala con Python 3.13/3.14, usa su lock correspondiente (existe y CI lo prueba).
